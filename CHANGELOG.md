# Changelog

All notable changes to cognix-terminal will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of cognix-terminal
- VTE/ANSI parsing module with C0/C1 control characters
- Grid state management with memory-optimized cells
- Terminal mode management with TermMode and KeyboardModes
- PTY I/O layer for Unix systems
- Text-based rendering with ANSI color support
- 6 example programs demonstrating core functionality
- CI/CD workflows for testing and publishing
- Comprehensive documentation

### Changed
- Implemented terminal emulation core
- Optimized for standalone usage
- Simplified API for easy integration
